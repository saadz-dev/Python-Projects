# Python-Projects
This repository contains small Python projects created to practise core programming concepts such as user input, data types, and file handling.

## Projects

### Daily Activity Tracker
A command-line Python application that allows users to log daily activities and the time spent on them. The program stores activity logs in a text file so data persists across runs.

### Password Strength Checker
A command-line Python application that validates password strength using conditional logic, string analysis, and loops. The program provides feedback and continues prompting until all criteria are met.
